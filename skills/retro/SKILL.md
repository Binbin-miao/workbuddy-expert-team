# /retro — 工程复盘与环境持续进化

## 复盘转化法则
1. **机械性错误** → 转化为确定性测试、Linter 规则或 `/setup-pre-commit` Git 钩子。
2. **认知与判断偏差** → 提炼为精炼条款更新至 `AGENTS.md` / `CLAUDE.md` 或 `GLOSSARY.md`。
