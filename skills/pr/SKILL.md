# /pr — 高信噪比 PR 与交付报告生成

## 标准模板
1. **Why & What**：核心问题与改动摘要。
2. **One-way vs. Two-way Doors**：标注需重点复核的不可逆/高成本单向门变更。
3. **Verification Evidence**：实际运行的测试命令、结果与前后对比证据。
