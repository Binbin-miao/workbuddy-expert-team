# /code-review — 并行双轴代码审查

## 审查双轴
1. **轴一：编码规范与深模块健康度（Standards & Architecture）**：检查深模块边界、信任边界校验、错误处理、安全防护与测试有效性。
2. **轴二：规格与需求忠实度（Spec Faithfulness）**：逐项核对 `SPEC.md`/Ticket 验收标准，确保零遗漏、零曲解、零未经请求的越界功能。
