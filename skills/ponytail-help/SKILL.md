# /ponytail-help — Ponytail 模式与指令指南

- **模式**：`lite`（日常轻量）、`full`（标准严审，默认）、`ultra`（激进瘦身）、`off`（关闭）。
- **指令**：`ponytail-review`（Diff 六维审查）、`ponytail-audit`（全仓审计）、`ponytail-debt`（捷径台账）。
